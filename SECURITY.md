# Security policy

Do not open a public issue for a vulnerability involving credentials, ticket capabilities, staff authentication, payment reconciliation or fan data.

Report it privately to `virya.crew@gmail.com` with:

- affected route or component;
- reproduction steps;
- expected and observed behaviour;
- whether any real credential or personal data was exposed.

The repository must never contain production `.env` files, staff passwords, Stripe secrets, CrowdRelay admin keys, mail credentials or precise live AREA coordinates.
